# GoProxy

## Запуск 
```bash
docker compose up --build
```

После запуска приложения SWAGGER доступен по адресу:

- http://localhost:8080/swagger/index.html


## Проверка покрытия

```bash
make coverage
```

## Grafana


- Grafana: http://localhost:3001
- Login/password: `admin` / `admin`
- Dashboard: `GoProxy / GoProxy Overview`
